REST API Endpoints

Machine-readable schemas are published in /data/openapi.json.

GET /api/v1/status

Returns gateway version, active region, and current operational status.

HTTP/2 200 OK
{"service":"__BRAND__","domain":"__DOMAIN__","api_version":"v__VERSION__","region":"__REGION__","status":"operational"}

GET /api/v1/health

Lightweight liveness probe for load balancers and synthetic monitors.

HTTP/2 200 OK
{"ok":true,"uptime":"__UPTIME__"}

POST /api/v1/auth/token

Exchanges OAuth2 client credentials for a short-lived signed JWT bearer token.

HTTP/2 401 Unauthorized
{"error":"unauthorized","message":"Valid client_id and client_secret required"}
