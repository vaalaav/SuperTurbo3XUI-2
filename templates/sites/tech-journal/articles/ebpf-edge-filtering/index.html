Stateless Edge Filtering with XDP and nftables Sets

High-volume internet scanners constantly probe TCP/443 across public cloud prefixes. When every invalid SYN or HTTP scan allocates a stateful connection tracking entry, memory pressure spikes before user-space proxies even inspect a request.

1. Separating L3/L4 Sets from Conntrack

By evaluating CIDR prefix sets in the ingress or prerouting hook prior to stateful tracking, kernels drop noisy traffic in nanoseconds per packet. Our testbed in __REGION_CITY__ observed median handshake latency remaining steady at __LATENCY_MS__ ms even under synthetic SYN floods.

table inet edge_filter {
  set blocked_v4 {
    type ipv4_addr
    flags interval
    auto-merge
  }
}

2. Key Takeaways

  • Always use flags interval with auto-merge for large CIDR lists to prevent O(N) rule traversal.
  • Keep rate-limit zones isolated in Nginx for application-layer bursts while letting nftables handle known bad prefixes.
